# FH Radio Studio 扩展版本：新增功能概览

在原项目的歌曲导入、AI 分析和准备包工作流上，增加更方便的人工配置、批量数据交换及电台管理功能。扩容版与 LoopLab 共享以下改进，LoopLab 另有循环分析功能。

## 轻量配置与精细编辑

增加“无 AI”模式和批量波形分析，可直接手动配置六个时间点；支持 PL 自动同步 TL、临时解除同步和单次复制。人工精修增加缩放概览、Ctrl+滚轮缩放、建议切换、返回已保存配置，以及循环两端同时移动。快捷键可以自定义，切歌可以首尾循环。

![人工精修与缩放概览](images/studio/manual_regular.png)

## 批量导入、导出时间点

支持文本、表格、CSV、JSON、XLSX 等导入，并可导出 CSV。时间点可留空，支持多种歌曲匹配方式及可选电台分配。新增 **48000 Hz 整数采样点**形式，可保留采样点精度；也可直接读取 **RadioInfo XML 的赛事列表**，自动匹配歌曲及时间点，按需导入赛事电台归属。

![采样点批量导入与预览](images/studio/import-samples_regular.png)

## 更快捷的电台管理

池子支持多选和批量分配；自建歌曲与编辑页可以快速分配，弹窗内用数字键 1–9 选电台。未完成配置的歌曲可以先排入电台，界面会醒目提示，构建前统一检查。播放列表新增保存、撤销与重做，并支持双击自建歌曲进入编辑。

![电台排布、布局调节与歌曲池](images/studio/playlist_regular.png)

## 扩容、构建质量与可调界面

支持电台扩容、构建质量滑块和九个电台文件的大小预估。电台列数、高度以及“一行／全部电台”显示可直接调整；自建歌曲表格列宽、人工精修窗口宽度和界面宽度也可调节。增加任意强调色与色盘，改善窄窗口、深色模式和大量歌曲时的操作体验。

![可调整列宽的自建歌曲列表](images/studio/library_regular.png)

## LoopLab 额外功能

集成来自 **SeamlessLoopMusic** 的循环查找引擎，在无 AI 模式下也能生成 TL/PL 循环建议；支持批量分析、缓存、试听和人工微调。基础设置注明功能来源并提供原项目 GitHub 入口。

本文以 2026-10-16 核对的上游项目源码 `fb787b6` 为比较基线。截图由当前扩容版的真实 Windows Flutter 界面生成，使用独立项目副本；两版的差异与完整规则见[详细版](改动说明-详细版.md)。
