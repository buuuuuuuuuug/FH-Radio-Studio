# FH-Radio-Studio-Improve：功能与优化说明

当前维护 **LoopLab** 版本。本文按使用场景介绍功能与操作规则，界面概览见 [README](../README.md)。

## 功能引导与演示歌曲

- 首次进入基础设置、歌曲库、歌曲编辑、人工精修、播放列表和设置时，画框介绍当前区域的核心功能。
- 右上角问号可重新打开当前页面介绍，支持上一步、下一步与跳过。
- 新建工程自动导入一首原创合成演示曲，用于串联体验歌曲库、时间组与人工精修，完成介绍后可删除。
- 歌曲介绍按时间组、波形、详情、试听设置、分析信息及浏览保存的顺序展开。

## 1. 分析模式与循环建议

### 手动与 AI 工作流

- 提供无 AI、中杯、大杯、超大杯分析模式，按需要选择手动配置或本地模型分析。
- 无 AI 模式独立读取波形，支持直接选点、输入时间、试听和确认。
- “分析全部波形”支持进度、缓存复用和取消；波形读取与点位确认分别管理。
- 基础设置集中管理安装目录、语言、分析模式、循环同步与实验功能。

### SeamlessLoopMusic 循环建议

- 使用 CPUrising / SeamlessLoopMusic 的 `loopfinder` 原生引擎查找 TL／PL 循环段，无 AI 模式也可使用。
- 新用户默认启用循环建议，已有用户的开关选择保持不变。
- AI 模式使用模型的节拍、结构和 TD／PD 分析，TL／PL 使用原生循环引擎候选。
- 每首歌曲最多提供十组有效候选；精修侧栏支持切换、套用和比较已保存配置。
- “分析全部循环”串行处理歌曲，支持进度、取消、缓存与结果查看。
- 缓存按音源、文件状态、引擎和参数区分。循环分析与已确认点位独立保存。
- 支持中文／日文路径、源音频采样率转换及独立进程分析。
- 匹配百分比用于参考，最终衔接效果通过拼接试听确定。

## 2. 歌曲库与连续编辑

- 支持本地音乐导入，以及塞壬唱片浏览、试听与导入，展示歌曲名、歌手、封面和时长。
- 汇总歌曲总数、配置完成数、待完成数与未分配数；列表显示四组配置进度及电台归属。
- 按歌曲、歌手、文件名搜索，结合配置状态、分配状态、电台及“可能重复”筛选。
- 支持编辑器顺序、歌曲名、修改日期及正序／倒序排列，搜索与筛选可组合使用。
- “可能重复”按曲名、歌手与近似时长提供核对线索；导入时对相同文件内容进行哈希识别。
- 表格列宽可拖动调整，双击恢复默认；歌曲操作区提供四组快速试听、编辑与分配入口。
- 编辑页提供上一首、下一首及当前序号，按进入时的列表顺序连续编辑。
- 从播放列表进入歌曲后可返回原页面，保留当前会话的搜索、筛选和滚动位置。
- 返回、换歌或关闭窗口时提供未保存内容处理选项。

## 3. 时间点与循环同步

| 时间组 | 配置内容 |
| --- | --- |
| TD · TrackDrop | 比赛开始时的播放起点 |
| PD · PostDrop | 冲线后的播放起点 |
| TL · TrackLoop | 比赛循环的 A／B 端点 |
| PL · PostLoop | 冲线循环的 A／B 端点 |

- 四组共六个时间点，分别确认后保存。
- PL 自动同步 TL 可关联循环起止点与确认状态；当前歌曲可临时调整同步状态。
- 全局同步关闭时，可通过“一键同步 TL”执行一次复制。
- 同步操作支持撤销，点位完整性检查包括六个值、时长范围与循环顺序。
- 双击配置卡片进入精修，`Ctrl + 右键` 快速确认；再次查看已确认组时保留确认状态。
- 卡片按 TD、TL、PD、PL 排列，悬停时高亮；`Ctrl + 左键` 可快速试听。
- 已保存配置、当前编辑草稿与分析建议分别管理。

## 4. 波形定位与人工精修

### 波形与播放

- 独立读取并缓存高分辨率波形，主页面与精修使用细条显示和时间网格。
- 旧预览缓存自动升级，AI 分析后继续使用详细波形，支持整曲与局部放大观察。
- 主界面和精修均支持 `Ctrl + 滚轮` 缩放；全曲概览中的高亮框可点击或拖动平移。
- 播放指针支持定位，放大播放到视窗边缘时按范围翻页。
- 波形与节拍可分别显示；有段落数据时展示对应信息。
- 主页面和精修各自控制播放进度，精修可将当前播放位置写入选中端点。

### 端点编辑

- 点击或拖动波形端点、直接输入时间，按一拍、10 ms 或 1 ms 微调。
- 时间输入支持秒数、分:秒.毫秒、时:分:秒及带单位形式，统一显示三位毫秒。
- 长按按钮或方向键可连续微调；循环两端可一起平移并保持长度，到边界时一同停止。
- 支持磁吸到拍、临时自由放置和固定自由放置。
- 精修草稿支持独立撤销，建议套用、恢复配置与连续微调纳入编辑记录。
- 可恢复磁盘中已保存的配置，确认后返回歌曲页保存。

### 统一试听

- 歌曲列表、编辑器和精修共用试听设置。
- TD、PD 分别设置试听时长（1–30 秒，默认 6 秒），与循环衔接前后时长、重复次数和音量一起保存。
- 可设置前后各 0.5–10 秒、1–10 次或持续循环，以及 0–100% 音量。
- 循环试听围绕 B→A 衔接播放，支持调整后反复比较。
- 播放器跨页面复用，保持常用页面之间的试听与切换效率。

## 5. 时间点批量导入导出

### 表格与文本

- 支持粘贴文本、Excel 复制内容，以及 TXT、CSV、TSV、JSON、XLSX 文件。
- 正式表头为 `Filename,TD,PD,TL-A,TL-B,PL-A,PL-B`，兼容旧端点列名及循环范围列。
- 可按文件名、歌曲名、歌曲名_歌手、歌手_歌曲名匹配；自动模式接受唯一匹配。
- 可选 `Radio_station` 列，支持 R1–R9 或 1–9，多电台以分号分隔。
- 支持不完整点位、默认保护已有时间组、可选覆盖，以及完整时间组自动确认。
- 先预览匹配、点位与校验结果，再执行导入；导入前备份原点位。
- 校验时间格式、范围、循环顺序、表头、重复歌曲冲突及容量；输入上限为 8 MB、10,000 行。
- 导出已保存点位为带 UTF-8 BOM 的 CSV，可包含已保存播放列表的电台归属。
- 导入与导出窗口空闲时可点击外部或按 Esc 返回，执行操作期间保留关闭保护。

### 48000 Hz 整数采样点

- 时间和整数采样点两种形式可选；采样点固定以 48000 Hz 为基准，每声道帧位置除以 48000 得到秒数。
- 采样点导出直接取最近整数，支持单采样点精度往返。
- 采样点 CSV 带 `SampleRate` 列，每行固定为 `48000`；导入可自动识别或手动选择单位。
- JSON 支持 `markers_samples`、`sample_rate: 48000` 或 `time_unit: "samples"`；`markers_sec` 表示秒数。
- 未包含的列保留原值；覆盖模式下明确留空的节点可清除，空白节点保持未配置。

```csv
Filename,Radio_station,SampleRate,TD,PD,TL-A,TL-B,PL-A,PL-B
示例歌曲.wav,R1,48000,920880,,3199680,9882384,,
```

示例 TD 对应 19.185 秒。

### RadioInfo XML

- 支持选择 XML 文件或粘贴内容，读取 R1–R9 的 Event（赛事）播放列表。
- 根据 Event 条目关联 Track Sample，再按曲名和歌手唯一匹配本地歌曲。
- 支持六个节点属性与 Marker 子节点，采样率要求为 48000；`-1` 表示未配置。
- 可按 XML 电台归属更新赛事播放列表草稿，漫游列表独立保留。
- 同曲多电台的相同节点可合并归属；节点、容量和匹配结果在预览阶段检查。
- XML 仅交换时间点与归属，音频仍由本地歌曲提供。

## 6. 电台分配与播放列表

### 分配与场景

- 歌曲库和编辑页提供快速分配，窗口展示电台名称、容量及分配后数量。
- 支持主键盘／数字小键盘 1–9 选择 R1–R9。
- 未完成配置的歌曲可先分配，卡片以确认进度标示，构建前统一检查。
- 播放列表提供游戏内排布与准备包草稿视图，可分别编辑漫游／比赛或同步使用统一排布。
- 支持拖动排序、跨电台移动、移回歌曲池、恢复原版，以及批量分配。
- 池子支持 Ctrl 多选、Shift 连选、全选筛选结果、清空选择及 Esc 退出多选。
- 点击改变选择，超过拖动阈值后显示组合卡片和数量。
- 批量分配统一检查容量；同一目标列表中的重复歌曲合并处理。
- 同一歌曲分配到多个不同电台时，在分配窗口、播放列表和构建前显示提示；同一电台的漫游与比赛分配不重复计数。

### 保存与撤销

- 播放列表草稿可独立保存，重启后恢复已保存排布；构建成功同步保存对应配置。
- 拖动、排序、移回池子、恢复原版及批量分配支持撤销与重做，批量操作作为一次记录。
- 当前会话最多保留 100 次记录，历史随项目与有效音源范围管理。
- “复制游戏内排布”提供覆盖当前草稿的提示。

### 电台扩容 · 实验功能

- 基础设置可启用超出原版槽位数量的自定义曲目。
- 构建同时生成新增声音所需的索引、名称、bank 结构与 XML 条目。
- 漫游与比赛共用 bank，容量按跨场景去重的实际音源数量计算。
- 关闭扩容前检查超量电台；bank 按小于 2 GiB 的限制校验。

## 7. 构建、空间与写入

- 构建窗口提供响度试听、Vorbis 质量 1–100（默认 50）及复位设置。
- 响度试听支持更换歌曲、拖动播放位置，便于比较不同片段。
- 展示九个主电台 bank 的大小预估与总计，预估考虑槽位重复、场景去重和扩容。
- 输入音源、点位、参数及产物均一致的电台可复用，按需构建变化部分。
- 格式转换和响度处理直接生成第一份槽位 WAV，重复槽位优先硬链接，其他文件系统使用复制。
- 每个电台最终 bank 校验完成后释放对应 WAV／FSB 中间文件；活跃电台并行处理。
- 构建前进行空间与数据完整性检查，未完成结果与可用准备包分别管理。
- 概览和播放列表提供打开准备包目录的入口。
- 默认写入 `mediapc` 覆盖目录，也可选择 `media`；窗口展示实际位置与受影响文件。
- 原始备份、部署记录和文件状态检查配合使用，写入按预检、暂存、替换顺序执行。

## 8. 界面与操作偏好

- 支持浅色／深色、任意强调色、侧栏／顶部导航，以及页面和精修窗口宽度调节。
- 电台列数提供自动或 2–6 列；高度支持手动、全部电台和一行电台模式。
- 表格提供可调列宽，长列表提供回到顶部入口，窄窗口支持适配和必要滚动。
- 标题、歌手、分配状态与主操作按可用宽度排列；精修建议集中在侧栏。
- 设置可点击主界面区域收起，提示浮层按状态区分，并支持长内容阅读与关闭。
- 底部操作提示使用彩虹边框，便于识别保存、分配及构建反馈。
- 快捷键可录入、保存、恢复默认并检查冲突，界面提示同步显示当前绑定。
- 波形、元数据及循环建议使用缓存；可见列表按需创建，布局调整合并保存。
- LoopLab 的用户偏好与验证设置分别管理，项目路径由用户选择。
